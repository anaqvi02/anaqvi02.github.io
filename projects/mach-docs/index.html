ORIGIN STORY

Why it exists.

Making mtdi forced me to learn the Mach IPC universe properly, and the useful information there is scattered thin: Apple's docs are sparse, the real knowledge lives in XNU source, and old blog posts drift. So I compiled the reference I wished existed: every function, right, and message type in one place, checked against the real SDK headers, with examples that actually run. For fun, mostly.

HOW IT WORKS

Ground Truth.

The whole thing is transcribed from the macOS 26.4 SDK headers, with every constant verified against them. It runs 363 function sections across 19 documents plus 7 reference essays on the conceptual core: ports, rights, message passing, MIG. Coverage is enforced, not claimed: 314 inventoried functions, each machine-checked into the docs by verify_coverage.sh.

HOW IT WORKS

Proof & Navigation.

Eleven example programs compile with plain clang and run correctly on macOS, including the port allocation and teardown cycles where most Mach examples quietly rot. There is an A–Z glossary in text and HTML, an INDEX.json that classifies every document and anchor for LLMs and crawlers, and a reading order for newcomers.
